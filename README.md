OXVO is an AI‑powered app builder and product analytics platform that enables teams to create, launch, and continuously improve web and mobile applications. It offers a unified dashboard for traffic, conversion, retention insights, and AI‑driven recommendations, along with tools like auto‑improve studio, co‑browsing, and omnichannel inboxes. OXVO aims to simplify the product lifecycle from development to growth, providing free and paid plans for individuals, startups, and enterprises.

**Areas:** AI · App Builder · Analytics · Product · Platform · SaaS

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for OXVO: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
